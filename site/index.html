Turn the files in your folder into a conference talk.

A Claude Code skill that reads your manuscript, figures and data, then builds a PowerPoint deck where every slide states a finding, every chart is fully labelled, and every number is checked against your files. Speaker notes included.

Install the skill View on GitHub

What every slide gets

Consulting-style clarity without losing scientific rigour. The letters match the markers on the example slide.

  • A
    A title that states the findingActive voice, the result and its size. Read in order, the titles tell the whole story.
  • B
    One message, at most three topicsAnything more is split onto another slide rather than crammed.
  • C
    Charts labelled like a paperBoth axes carry quantity and unit, built only from numbers found in your files.
  • D
    Method details in the footnoten, p-values, confidence intervals and validation schemes sit in small type, out of the way.
  • E
    A source on every piece of evidenceFile plus table or figure number, so reviewers can trace each claim.
  • N
    Notes you can read aloudTimed, plain English speaker notes for every slide, visible only in presenter view.

How it works

  1. 1Gather your material

    Put the manuscript, figures, data and the journal's author guidelines in one folder.

  2. 2Answer one round of questions

    Talk length, target journal or audience, which files count as sources.

  3. 3Approve the storyline

    Read the slide titles and timings, and change the story before anything is built.

  4. 4Let it build and check

    Every number is matched to your files and every slide is rendered and inspected.

  5. 5Open your deck

    The .pptx lands in your folder next to your files; nothing is overwritten.

Your files stay with you

The skill runs inside Claude Code on your own computer. It uses only the content of your folder and never invents numbers.

  • The only web page it reads is the target journal's public aims and scope.
  • Working files live in a temporary directory; only the finished deck is written to your folder.
  • Nothing is uploaded to this repository.

Install

You need Claude Code, Git, Python 3 and Node.js. PowerPoint or LibreOffice enables the visual check of each slide.

macOS, Linux or Git Bash
git clone https://github.com/jark13/prezentacja-mckinsey.git ~/.claude/skills/prezentacja-mckinsey
Windows PowerShell
git clone https://github.com/jark13/prezentacja-mckinsey.git "$HOME\.claude\skills\prezentacja-mckinsey"
Then, in the folder with your material
claude
> Build a 12-minute talk from the files in this folder

Restart Claude Code after cloning; the skill then appears in /skills. Update later with git pull in the skill folder.
